# Crack Detection and Analysis System

A computer vision-based crack detection and analysis system developed using Python and OpenCV. This project focuses on identifying cracks from images and videos using image preprocessing, edge detection, contour analysis, and feature extraction techniques.

---

## Features

- Crack detection from images and video streams
- Edge-based crack analysis
- Left and right edge crack prioritization
- Noise reduction and preprocessing
- Contour extraction and filtering
- Crack visualization with bounding regions
- Video frame processing support
- Performance optimized detection pipeline

---

## Installation

Clone the repository:

```bash
git clone [https://github.com/your-username/crack-detection-system.git](https://github.com/Gajan-lab/road-damage-enhancement-dataset.git)
```

Move into the project directory:

```bash
cd road-damage-enhancement-dataset
```

Install required dependencies:

```bash
pip install opencv-python numpy matplotlib jupyter
```
